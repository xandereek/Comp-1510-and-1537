# COMP 1510 Lab 06 - Word Game Scoring Engine

Follow the lab handout (PDF) for the full requirements.

`wordgame.py` is the program you complete. `words.py` holds the list of
valid words, and you do not need to open it. Finish the starter tests
in `tests/test_lab06.py`: three examples show the pattern, and you add
tests for every function.

`main()` starts with one line that brings in the word list. Leave it
alone. You add the rest in Question 3.

Submit `wordgame.py` and `test_lab06.py` to the Lab 6 dropbox in
Learning Hub before the deadline.
